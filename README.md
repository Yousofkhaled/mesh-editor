A base project that I will use to apply computational geometry concepts as I learn them.
My reference will be the book Real-Time Collision Detection by Christer Ericson(https://realtimecollisiondetection.net/books/rtcd/).

It uses raylib(https://github.com/raysan5/raylib) as a base.
